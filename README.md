### **SLICERS**
- Slicers are interactive filters used to filter report visuals dynamically. 
- They improve user experience by enabling easy data analysis and navigation. 
- Common slicer types include List, Dropdown, Date, Range, and Hierarchy slicers. 
- Slicers can filter multiple charts and KPIs simultaneously. 
- They support single-select and multi-select filtering options. 
- Slicers help users focus on specific regions, categories, products, or time periods. 
- Power BI also supports syncing slicers across multiple report pages. 

### **FILTERS**
- Filters in Microsoft Power BI are used to display only relevant data in reports and dashboards. 
- Power BI supports three main filter levels: Visual-level, Page-level, and Report-level filters. 
- Visual-level filters affect only a single chart or visual. 
- Page-level filters apply to all visuals on a specific report page. 
= Report-level filters impact the entire report across all pages. 
- Filters improve report accuracy, readability, and user interaction. 
= Advanced filters allow conditions such as Top N, greater than, contains, and date ranges. 
- Filters can be combined with slicers for more dynamic and interactive analysis.
